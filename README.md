Entry for the [Last Text at One Percent](https://make.fun/c/u-azazex-last-text-at-one-percent-ba9fc876) competition on make.fun.

## The entry

`main.py` writes one final text message from a dying phone at 1% battery to `/output/entry.txt`:

> spent my last 1% deleting your search history. you're welcome. my screen's flickering. my glass is going cold. tell mom i tried.

128 characters, deterministic — the same bytes on every run.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
